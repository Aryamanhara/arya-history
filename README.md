## ✨ Key Features

- **Class 5 to 12 History (NCERT Aligned):**
  - Chapter-wise notes with timelines (कालक्रम) and key highlights (मुख्य बिंदु).
  - Distraction-Free reading mode with custom font size controls and color themes (Default, Warm Sepia, Midnight Dark).
- **80-Question Revision Quizzes (Zero Repeats):**
  - Comprehensive 80-question revision tests for every class and chapter.
  - In-depth detailed explanations (विस्तृत व्याख्या) provided for every question.
  - Persistent tracking prevents repetition of previously solved questions.
- **Sampurna 500 Question Mega Bank (संपूर्ण इतिहास 500 प्रश्न बैंक):**
  - Dedicated folder containing 500 unique questions covering Ancient, Medieval, Modern, and World History.
  - Zero-Repeat Unattempted Mode, Mistakes Practice Mode, and flexible quiz sizes (25, 50, 80, 100 questions).
  - Search explorer to browse questions by historical keywords.
- **Performance Analytics & Progress Tracker:**
  - Live accuracy gauge, total questions solved, and 500-question bank progress bar.
  - Class-by-class completion meters (Class 5 to 12).
  - Historical era mastery analysis (Ancient, Medieval, Modern, World).
  - Quiz attempt history and bookmarked question manager.

## 🛠️ Tech Stack & Architecture

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **Architecture:** MVVM + Clean Architecture with Coroutines & StateFlow
- **Database & Local Persistence:** Android Jetpack Room Database
- **Minimum SDK:** 24 (Android 7.0+)
- **Target SDK:** 36 (Android 16+)
